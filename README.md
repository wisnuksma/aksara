# Novel Writer

Aplikasi menulis novel (PWA untuk Chrome di Mac). Spesifikasi lengkap: `CLAUDE.md`.

## Menjalankan di Mac

1. Pasang Node.js (versi LTS) dari https://nodejs.org (sekali saja).
2. Buka Terminal, masuk ke folder ini, lalu jalankan:
   - `npm install` (sekali saja, atau setiap ada library baru)
   - `npm run dev`
3. Buka alamat yang muncul (biasanya http://localhost:5173) di Google Chrome.
